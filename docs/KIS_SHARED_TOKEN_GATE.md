# MD-02D — KIS 토큰 공유 상태 및 호출 제한 (2026-11-20)

상태: **GitHub 코드/오프라인 합성 테스트 전용. 운영 미연결.** 2026-11-20 최초 실전 읽기 전용 호출(P0 1회 + 국내/해외 일봉 각 1회)은 승인 후 성공했지만, 당시 토큰은 단발 프로세스 메모리에만 존재하여 이번 상태 파일에 이관되지 않았다. **추가 발급·재호출하지 않는다.**

## 구현
- backend/app/kis_shared_state.py: Linux 단일 호스트·동일 Unix 사용자·로컬 파일시스템 flock 배타 잠금. 잠금 중이면 즉시 fail-closed.
- 상태 폴더는 사전에 마련한 동일 소유자의 0700 디렉터리, 잠금·상태 파일 0600 일반 파일만 허용. symlink, 권한 불일치, 손상 상태, 시계 역행 거부.
- 공유 상태: 접근 토큰(로컬 0600 파일에 평문 저장), 만료 시각, App Key SHA256 식별자, 마지막 토큰 시도 시각, 일봉 호출 시각, 최근 24h 요청 내역. **토큰은 저장 시 암호화하지 않으므로 홈 백업/스냅샷 접근제어·암호화 필수.** App Key/Secret 원문은 공유 상태에 기록하지 않음.
- 새 토큰 발급은 기본 거부. 별도의 명시적 개발자 옵션 allow_shared_token_issue=True 및 live_enabled=True로만 활성화할 수 있으나 운영에서는 미연결·비활성. 기존 1회 시도 후 토큰 상태가 비어 있다고 자동 발급 금지.
- 동일 키 기준 24시간 내 토큰 재발급 시도 금지(실패 시도도 소비), 일봉 간격 1.25초, 토큰+일봉 합산 최근 24시간 시도 60회 상한. 이는 KIS 공식 한도 보장 값이 아니라 **앱 자체 보수적 안전 상한**.
- 네트워크 이전 상태 예약 및 fsync/원자적 교체로 crash 이후 자동 재시도 방지. 중복 발급/병렬 호출 시 즉시 거부. 주문·잔고·다른 호스트/URL 추가 없음.
- MD-02 기존 클라이언트에 optional shared_state만 추가. 기존 모드 비활성 기본값 유지. scheduler/서비스 API/운영 Compose 연결 없음. is_final=False, source_observed_at=None 유지.

## 제약 및 추후 승인 게이트
1. 이번 코드로 **2026-11-20 이미 발급한 실 토큰을 되찾거나 재사용할 수 없다**. 사용자의 기존 일회성 probe 마커를 삭제하거나 새 토큰을 발급하지 않는다.
2. 다른 사용자/호스트/NFS/독립 볼륨 간 rate limit은 공유되지 않음. 운영 Compose에 마운트할 경우 UID, 파일 접근제어, 영속 디스크, backup 암호화 별도 검토 필요.
3. 2026-11-20 사용자가 받은 KIS 토큰 알림의 내용은 유효기간 24시간, 하루 1회 발급 원칙. 최신 공식 서비스 정책·호출 한도 및 잔여 토큰 주기 확인 후 운영 적용.
4. 장마감 finality, 조정가격, 지연 시각, 비거래일 품질, price_bar DB 적재/멱등, UI·자동 스케줄러는 후속 개발에서 별도 승인.
5. 이 PR에서 비밀 파일 접근/새 API 요청/DB migration/Docker/Frontend/Traefik/기존 백업 타이머 변경 없음.

## 합성 테스트

## 리뷰 보완: 상태 파일 유실 후 토큰 재발급 차단 (2026-11-20)
- **실제 결함 방지:** 캐시 JSON을 삭제하면 마지막 발급 시각까지 사라져, 이후 새 발급 허용 플래그를 실수로 켰을 때 발급 제한을 우회할 가능성이 있었다.
- 토큰 발급 시도 전에 `kis-ever-attempted-token.marker`를 0600의 독립 영속 파일로 만들고 fsync한다. 상태 파일이 없는 상황에서 마커가 존재하면 `KIS_SHARED_STATE_LOST_AFTER_ISSUE`로 **일체의 재발급/시세 호출을 거절**한다.
- 토큰 발급 실패/프로세스 중단 시에도 마커 유지. 복구는 운영자 승인과 발급 이력 검증이 필요한 **별도 수동 절차**이며 이 PR에는 마커 삭제/리셋 명령이 없다. 기존 2026-11-20 단발 실전 토큰이 자동 공유 캐시에 들어온 것은 아니다.
