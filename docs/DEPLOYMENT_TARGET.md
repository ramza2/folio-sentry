# FolioSentry — 개인 MiniPC 배포 대상 및 외부 LLM 연계

작성: 2026-11-18. 이 문서는 **운영 목표**이며 현재 배포되었음을 의미하지 않는다.

## 결정된 사항
- 설치 대상: 사용자의 **집에 있는 개인 MiniPC**. 회사 GPU 서버에 FolioSentry 애플리케이션/DB/스케줄러를 배포하지 않는다.
- 운영 방식: 1인 개인용, Docker Compose 단일 인스턴스. Backend(FastAPI), Frontend, PostgreSQL. 자원 부족 시 개발용 Vite 서버는 운영용 정적 빌드 + 웹서버로 전환.
- 매수·매도 주문 API는 사용하지 않는다.
- LLM은 선택적 뉴스 요약/설명 기능에만 사용하며 **필요 시 기존 ModelOps Gateway API를 원격 호출**한다. MiniPC에 자체 LLM 모델 설치는 기본 범위가 아니다.

## 배포 전 확인해야 할 사실 (아직 미확인)
- MiniPC CPU/메모리/디스크와 운영체제, Docker/Compose 버전 및 기존 서비스의 사용량
- Compose 프로젝트 간 격리, 포트 충돌 여부, 저장 경로/볼륨, 백업 위치
- 집에서만 접속할지, 외부 모바일에서 확인할지; 접속 방식(VPN, 인증된 프록시, TLS)
- 정전/재부팅 후 자동 복구, DB 백업/복원 및 디스크 부족 경고
- 뉴스/시세 공급자 API 개인용 사용조건, IP 제한, 통신 요금
- ModelOps Gateway의 **개인적 사용 허용 여부**, 호출 주소와 인증/허가된 모델, 네트워크 경로, 원문 기사/데이터 전송 및 저장·감사 정책

## 권장 컴포넌트
```text
집 MiniPC (Docker Compose / private)
  ├─ frontend: 생산용 정적 사이트 + 인증된 접근 경로
  ├─ backend: 종목/차트/신호/뉴스 API + 스케줄러(중복실행 방지)
  └─ PostgreSQL: 외부 포트 비노출, 독립 볼륨

Backend → 시세/뉴스 제공처 API (최소 호출·캐싱)
        → 이메일/FCM (요청된 알림에 한정)
        ⇢ [선택적, 허용 확인 후] ModelOps Gateway API (LLM 뉴스 요약만)
```

## ModelOps Gateway 어댑터 설계
- `LLM_ENABLED=false` 기본값. 연결정보가 없으면 요약 영역에 “AI 요약 사용 안 함” 표시.
- `LLM_PROVIDER=modelops_gateway` 같은 설정 인터페이스를 **연동 단계에서** 추가하며, 현재는 실제 호출 코드를 작성하지 않는다.
- URL/키/모델 ID는 환경변수 또는 안전한 secret mount에 저장, GitHub/로그/이미지에 삽입 금지.
- Gateway로 보내는 데이터는 이용 허용 범위 안의 **기사 제목·공개 메타데이터·허용된 요약/발췌**로 최소화. 기사 전문 무단 전송 금지.
- 개인 보유 수량, 평균단가, 계좌번호, 투자 수익/개인 메모/알림 토큰을 Gateway로 보내지 않음.
- 요청 타임아웃·전송량/호출비용 제한·재시도 상한·실패 기록. 장애면 기존 기사 목록과 규칙 기반 신호 유지.
- LLM 출력은 출처를 가진 설명일 뿐, 지표·가격·규칙 엔진의 신호를 변경하지 않는다.

## 보안 및 운영 안전 게이트
1. 기존 MiniPC 서비스/볼륨/네트워크는 삭제·중단·재시작하지 않는다.
2. 사전 승인 전 서버의 컨테이너 실행, 공인 포트 개방, reverse proxy 설정 변경, DB 데이터 이관 금지.
3. PostgreSQL 외부 비노출, 개인 인증 필요. 로컬 바인딩 유지 또는 인증된 VPN/프록시 설계.
4. 비밀정보/실제 보유 자산은 저장소나 로그에 남기지 않고 백업 보관 정책 수립.
5. 개인 서버의 CPU/RAM/디스크에 무리가 없도록 수집 주기와 작업 동시성을 제약하고, 백업 복원 테스트를 수행.
6. 가정 접속과 ModelOps Gateway 경로를 섞어 **집 MiniPC에 회사 VPN/내부망을 무단 노출**하는 구성을 만들지 않는다.
