# MD-05C — 보유 종목 참고 평가손익 (2026-11-24)

## 목표
개인 보유종목의 직접 입력 수량·평균 매입단가와 MD05B에서 수동 조회한 KIS 제공 현재가를 연결한다. API에서 받은 Decimal 문자열을 브라우저에서 정확한 십진 고정소수점(BigInt)으로 처리한다. **실제 계좌 잔고 조회/확정 손익/실시간 시세가 아니다.** GitHub 개발 및 합성 테스트만 수행하고 운영 배포와 실 KIS 호출은 하지 않는다.

## 계산 및 표시
| 항목 | 계산 |
|---|---|
| 참고 평가금액 | 수량 × KIS 제공 현재가 |
| 매입금액 | 수량 × 평균 매입단가 |
| 참고 평가손익 | 평가금액 − 매입금액 |
| 참고 수익률 | 평가손익 ÷ 매입금액 × 100 |

수량·단가 최대 소수점 8자리/정수 16자리, 두 수의 곱은 소수점 16자리의 정수 계수로 저장하지 않고 메모리 계산. 표시 시에만 소수점 둘째 자리 반올림(half away from zero), 통화 표시. 합계도 반올림 전 값을 합산하고 마지막에 한 번 반올림하므로 표시된 행 금액의 합과 소수점에서 차이가 날 수 있다. JS Number로 금융 금액을 계산하지 않는다. 새 패키지 없음.

- 관심 종목은 평가 대상이 아님. 수량 누락/0 이하/비정상 숫자는 계산하지 않음.
- 원가 미입력은 평가금액만 계산. 0원가이면 매입금액 0과 손익 계산 가능하지만 수익률은 미표시.
- 현재가 미수신, 유효하지 않은 출처·통화, 위조 FINAL/REALTIME 응답, 이상 가격·시간대는 제외.
- 앱 수신 후 5분 미만인 값만 사용(브라우저 시계 기준, 5초 초과 미래 시각 제외). **이는 앱에서 받은 시각이지 공급자의 체결시각/지연 보증이 아니다.** 로컬 UI 시계만 갱신하며 네트워크 호출 없음. 재조회 실패·목록 새로고침·수정·삭제 시 기존 임시 결과 삭제. 페이지 이동 시 상태 사라짐.
- 세금, 수수료, 환전, 배당, 기업행동 및 실현손익은 포함하지 않음.

## 통화별 집계
KRW/USD를 별도 계산. 환율이 없으므로 합산하지 않음. 현재 불러온 전체 보유 목록(관심 제외, 필터와 독립)의 부분 집계이고 미로드 페이지가 있으면 안내한다.
- 평가금액은 유효한 현재가와 수량이 있는 행을 합산.
- 매입금액·손익·수익률은 같은 원가 입력 완료 부분집합을 사용. 평가금액의 대상과 다를 수 있음. 집계 수익률은 손익 합계/원가 합계 ×100이며 개별 수익률 평균이 아님.
- 포함 건수/로드된 해당 통화 보유 건수와 수신 시각의 최소~최대 표시. 계산 가능한 종목이 없으면 0이 아니라 —.
- 화면은 참고값이고 여러 시점에 수동 조회한 결과의 합이므로 계좌 실시간 총액이 아님.

## 기능 승인 및 API 호환
신규 GET /api/v1/market-data/valuation-capabilities는 로그인 필수, boolean만 제공. 기존 MD05B 읽기/표시 두 설정과 FOLIOSENTRY_MD05_VALUATION_DISPLAY_ENABLED=yes가 모두 필요(기본 OFF). 프론트의 표시 제어이며 서버의 가격 사용 권한이나 공급자 진위 증명은 아님.
기존 current-quote/quote-status/tracked API와 DB 스키마는 변경 없음. MD05A 과거 참고 일봉, DEMO, 자동 신호/알림과 분리. 현재가 버튼을 누를 때만 기존 KIS 수동 조회 경로 사용. 추가 가격 조회·토큰·스케줄러·DB 쓰기·브라우저 영속 저장 없음.

## 검증 및 후속 작업
Frontend 합성 소수점/손익 부호/반올림/매입가 누락·0/잘못된 시세/수신값 만료/통화 분리·부분 집계 및 capability parser 테스트. Backend 소유자 인증 및 capability 조회 시 DB·KIS 접근 없음/3개 플래그 검사 회귀. CI PASS 후 사용자 승인으로 병합한다.

**다음은 MiniPC 실제 연동 단계:** 배포 대상 Git SHA와 기존 DB 마이그레이션 상태·백업/복구 가능성·KIS 자격 파일/공유 상태 볼륨·토큰 발급 및 호출 한도 사전점검. 별도 사용자 승인 후 운영 배포, 실 KIS 조회 및 참고 시세/손익 활성화, 실제 화면 인수검사. 이 문서가 운영 실행 승인이나 API 사용 권한을 부여하지 않는다.
