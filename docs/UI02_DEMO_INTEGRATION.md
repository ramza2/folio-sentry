# UI-02 — Figma 화면과 DEMO API 연동 검증

작성일: 2026-11-18 · 상태: 기능 브랜치 / Draft PR 단계

## 목적과 안전 경계
- `GET /api/v1/demo/overview` 고정 허구 데이터를 화면의 **유일한 시세·보유·신호·뉴스 소스**로 사용.
- 사용자의 실제 주식, 계좌 정보, 개인 메모, 개인정보, 실제 뉴스·시세 API, 증권 주문 API, DB 구조에 접근하지 않음.
- 화면은 Figma 디자인 시연용이며 모든 숫자는 **DEMO**. 미래의 실 데이터 연동과 혼동하지 않도록 표시.
- 현재 MiniPC Docker 배포, 운영 포트 개방, PR 병합 없음.

## 구현
- `frontend/src/demoApi.ts`
  - DEMO 타입 계약, 런타임 응답 검증, `fetch`(AbortSignal/no-store).
  - 허위/누락된 응답을 무조건 표시하지 않고 오류 상태로 실패 처리.
  - Decimal 문자열 기반 금액·수량·퍼센트 표시. KRW/USD 별도 표시.
  - `UNAVAILABLE` 데이터에서 가짜 0원/0%를 만들지 않음.
  - 백엔드 신호의 설명/전략/근거만 표시. UI 자체 매수·매도 판정 금지.
- `frontend/src/App.tsx`
  - App 진입에서 DEMO API 1회 조회, 로딩·오류·재시도 UI.
  - 대시보드: 보유/관심 건수, 원화/달러 각각의 평가액, 신호/뉴스.
  - 내 종목: 한국/미국 및 HOLDING/WATCH 필터, 종목 검색, 선택 종목 상세 이동.
  - 종목 상세: 선택한 `instrument.id` 기준 시세/보유액/신호 근거/뉴스.
  - 뉴스: API 메타데이터와 출처/발행 시각. 데모 링크는 실제 원문이 아니므로 비활성.
  - 신호 이력: API 신호와 근거, 날짜 필터(추후), 실제 발송 이력은 없음.
  - 설정: DEMO 시연용 상태만 표시하고 시세 공급자 정상 연결 등의 가짜 상태 제거.
- `frontend/src/demoApi.test.mjs`
  - DEMO 데이터 검증, 무효한 응답 거부, 시세 없음, 가짜 잔고/신호 상태 거부, 소수 금액 처리, HTTP 실패 시 대체 데이터 없음 검증.
  - Node 내장 테스트 러너 사용. 새로운 테스트 라이브러리 의존성 없음.
- GitHub Actions Frontend 단계에 `npm test` 추가.

## 지금 동작하지 않는 기능 (의도된 제한)
- 실제 종목 등록/수정/삭제, 알림 토글 **영구 저장**, 설정 영구 저장
- 실 가격/차트 OHLCV, 거래소 장 운영 시간, 기술적 지표 계산 및 분석
- 뉴스 원문 조회/중복 뉴스 그룹핑/기사 전문, ModelOps Gateway AI 요약
- 이메일·FCM 알림 실제 전송 및 전달 상태
- 계정 API, DB 마이그레이션, MiniPC 운영 배포

원본 Figma 차트는 **과거 OHLCV 데이터가 없는 디자인용 선 그래프**로 남기고 화면에 명확한 경고를 표시한다. 데이터와 무관한 캔들/RSI/MACD 숫자를 진짜 계산 결과처럼 표시하지 않는다.

- CI: Backend pytest, Frontend DEMO adapter tests, Frontend Typecheck, Vite Build, Compose 설정
- 실 서버에서 실행한 브라우저 테스트는 아직 없음. PR 병합 전 데스크톱/모바일 브라우저에서 아래 확인 권장:
  1. 6개 화면 탐색, 라이트/다크 모드, 모바일
  2. 대시보드 KRW/USD 합계가 각각 분리되는지
  3. 삼성전자/NVIDIA/SPY 선택 시 서로 다른 데이터와 시세 없음 상태 반영
  4. 신호·뉴스 날짜가 가상의 API 기준 시각으로 표시되는지
  5. Backend 종료/잘못된 응답 시 값 없는 오류·재시도 UI, 이전 고정 시세 없음
  6. 화면에서 실제 주문/알림 발송이 발생하지 않음
