# FolioSentry PRD (초기 초안)

## 1. 목적 및 경계
사용자 1명이 국내(KOSPI/KOSDAQ)·해외(미국 NYSE/NASDAQ 우선) 주식과 ETF를 등록하고, 가격 추세 및 종목 관련 뉴스를 확인하고, 설명 가능한 매매 **검토** 신호를 알림으로 받는다.

- 서비스 성격: 개인 투자 의사결정 지원, **자동 거래 불가**
- 최종 배포: 사용자의 집에 있는 **개인 MiniPC**, 회사 GPU 서버 배포 대상 아님.
- AI 뉴스 요약(후속 기능)은 필요한 경우 기존 **ModelOps Gateway API**를 선택적으로 이용할 수 있음. 연결이 없어도 기본 기능은 동작해야 하며, 개인적 사용 가능 여부와 보안 정책 확인 후 연동한다.
- 계정/공개: 단일 사용자, 외부 공개 및 다중 계정 지원 제외
- 통화: KRW/USD, 원화 합산 평가는 환율 데이터 확보 후 지원
- 해외 시장 확장 가능하도록 식별자 모델 설계, MVP는 미국까지만
- 신호 표현: 매수 검토 / 매도 검토 / 관망 / 위험 경고 (매수·매도 확정 권유 아님)

## 2. 사용자 흐름
1. 보유 또는 관심 종목을 검색해 등록한다.
2. 보유 종목은 평균 매수가·수량을 선택적으로 입력한다.
3. 홈에서 시장·통화·종목별 시세 갱신 시각, 신호, 주요 뉴스를 확인한다.
4. 종목 상세에서 일봉 차트, MA/RSI/MACD/거래량, 전략별 판단 근거, 관련 뉴스를 확인한다.
5. 조건이 충족되면 중복 억제 후 알림을 발송한다.
6. 알림에서 신호 산출 시점·입력 데이터·분석 근거·원문 뉴스 링크를 확인한다.

## 3. MVP 기능
| ID | 기능 | 완료 조건 |
|---|---|---|
| P01 | 종목 검색·등록 | 시장·거래소·심볼 충돌 없이 보유/관심 종목 CRUD |
| P02 | 수동 보유 정보 | 수량/평균 단가 수정, 주문 기능 없음 |
| P03 | 일봉 OHLCV 수집 | 한국/미국 지원, 데이터 출처·시각·결측 표시 |
| P04 | 지표 계산 | MA20/60/120, RSI14, MACD(12,26,9), 거래량·ATR 등 검증 |
| P05 | 규칙 신호 | 버전 고정 규칙, 이유/값/충족 조건 저장, 오래된 데이터 시 억제 |
| P06 | 종목 뉴스 | 국내/미국 관련 기사 제목·출처·시간·링크, 중복 방지 |
| P07 | 알림 및 이력 | 개인 이메일, 종류/심각도/종목별 ON/OFF, 중복 방지 |
| P08 | 기본 웹 UI | 대시보드, 종목 목록/상세, 신호 이력, 설정 |
| P09 | 장애 가시성 | 시세 지연·API 실패·뉴스 부족 상태를 신호와 명확히 분리 |

## 4. 이후 단계
- Android FCM 푸시 및 딥링크
- AI 뉴스 요약·종목 관련성 분류 (사실 출처 포함, 없는 기사/시세 생성 금지)
- 전략 백테스트 및 성과 비교(비용·누락·상장폐지·편향 고려)
- 포트폴리오 손익/비중/환율 표시
- 중요도 기반 뉴스 속보, 시장 상태별 규칙, 선택적 증권 계좌 조회 연동

## 5. 알림 기본값
- 종목별로 마지막 완료된 거래일의 확정 일봉을 기준으로 장 마감 후 분석.
- 미국/한국의 휴장일·서머타임·거래소별 종가 반영 시점을 구분.
- 같은 종목/전략/신호/기준 봉 중복 발송 없음.
- 일반 뉴스는 일일 묶음; 중요한 이벤트는 나중에 별도 즉시 알림 지원.
- 데이터 누락/지연/비정상값 감지 시 신호 대신 수집 오류 표시.

## 6. 비기능 요구사항
- 데이터 원천/API 사용 약관·무료 한도 준수; 재배포 전제 없음.
- 계좌/실거래 연동 및 개인 보유 정보는 외부 LLM으로 전송하지 않음(명시적 허용 시 별도 설계).
- 뉴스 해석/AI 출력은 투자 성과를 보장하지 않으며 사실과 추론을 구분.
- 기준 시각(UTC + 시장 타임존), 데이터 버전 및 제공처 추적 가능.
- 개인 MiniPC에서 최소 운영비로 재시작·백업·복원 가능하며 다른 홈 서비스와 자원/포트 충돌이 없어야 한다.

## 7. 착수 전 검증 항목
- 한국투자증권 API로 국내·미국 주식의 일봉을 필요한 기간/호출량만큼 수집 가능한지 실계정 약관·한도 확인
- 국내 뉴스/미국 뉴스 공급원의 최신 가격·호출 한도·상업/개인 사용 조건 확인
- 시세의 수정주가 정책, ETF, 거래 중단, 상장폐지 처리
- 테스트용 데이터셋 및 결과 검증 기준 확정

이 문서는 제품 의도와 우선순위의 기준이며, API 선택은 실측·약관 검토 후 확정한다.
