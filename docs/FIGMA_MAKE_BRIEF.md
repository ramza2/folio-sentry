# Figma Make 의뢰용 디자인 브리프 — FolioSentry

이 문서는 Phase 1A API 계약을 기반으로 작성된 디자인 의뢰문이다.
Figma Make에서 **디자인/프론트엔드 프로토타입만** 생성하고 실계좌·실시세 API 연결이나 주문 동작은 구현하지 않는다.

## 목표
FolioSentry: 개인 1명이 국내/미국 주식 및 ETF 보유/관심 종목을 감시하고 차트 기술지표, 매매 *검토* 신호, 종목별 최신 뉴스, 알림 이력을 보는 한국어 서비스.

## 디자인 요구
- 데스크톱 1440×900 우선, 모바일 390px 반응형 추가.
- 금융 모니터링 워크스테이션 같은 간결하고 신뢰감 있는 UX. 과장된 AI SF 효과/광고/과도한 글래스모피즘 금지.
- 명확한 정보 계층: 시장/통화, 시세 상태, 신호 상태, 갱신 시각, 출처를 우선.
- 기본 라이트 테마 + 선택적 다크 모드 컴포넌트. 한국어 가독성 높은 Pretendard 또는 적합한 대체 글꼴.
- 색만으로 상승·하락/위험을 구별하지 말고 +/−, 텍스트, 아이콘 병기.
- 숫자 우측 정렬, 동일 통화별 구분자/소수 자릿수, 환율 없이 KRW·USD 합계 섞지 않기.
- 임의의 실시간 정확도·수익률·AI 승률, “강력 매수” 같은 오해 유발 표현 금지.

## 필수 화면
1. 대시보드: 보유/관심 수, KRW/USD 개별 평가액, 국내/미국 시장 상태, 주요 신호, 최신 뉴스, 수집 상태/시간.
2. 보유·관심 종목: 표/카드 토글, 시장 필터, 검색, 추가/수정 모달(수량/평균단가), 제거 확인, 시세 없음/로딩/빈 상태.
3. 종목 상세: 종목명/거래소/통화, 1D/1W/1M/3M/1Y 차트 기간 전환, 일봉 캔들/거래량, MA20/60/120, RSI/MACD 보조 영역, 신호 판단근거 패널, 종목 관련 뉴스, 출처 링크.
4. 뉴스: 관련 종목, 제목, 발행사, 발행 시각/타임존, 원문 열기, 중복기사 그룹, “관련성 검토 필요” 상태.
5. 신호·알림 이력: 매수 검토/매도 검토/관망/위험 경고, 시점, 근거, 알림 전송 결과, 필터.
6. 개인 설정: 국내/미국 알림 시간대, 이메일/FCM 전송 채널 토글(FCM 준비 중), 데이터 출처·API 연결 상태(placeholder), 라이트/다크 전환.

## 상태 디자인
- 데이터 없는 상태/로딩/오류/오래된 시세/장 휴장 상태
- 알림 권한 없음/전송 실패/재시도 UI
- DEMO 배지 및 경고: **"예시 데이터이며 실제 시세·매매 신호가 아닙니다"**
- 환율 미지원 시 통화별 평가액만 보이고 전체 합산 없음
- 매수/매도는 "검토 신호"로만 표기, 자동매매/주문 UI 절대 넣지 않기

## 인터랙션 시연
- 좌측 내비게이션: 대시보드 / 내 종목 / 뉴스 / 신호·알림 / 설정
- 종목 클릭 → 종목 상세, 탭 전환, 필터, 추가/수정 모달, 알림 읽기/메뉴 이동
- 화면 간 동일한 샘플 종목·상태 유지
- 리얼타임 API 호출 불필요. 프론트엔드 컴포넌트·mock 데이터만.
- 접근성: 키보드/포커스, 충분한 대비, 표의 수치 정렬, 모바일 터치 타깃.
- Auto Layout/재사용 컴포넌트·디자인 토큰·명료한 이름을 사용하여 개발자가 구현하기 쉽게.

## 예시 데이터
- 삼성전자 005930 / XKRX / KRW (보유, 예시 수량/매수가)
- NVIDIA NVDA / XNAS / USD (보유)
- SPY / ARCX / USD (관심 ETF)
- 모든 가격/손익/뉴스/신호는 가상의 DEMO 수치/제목이며 실제 시세가 아니다.
- 시장별 수익률·통화합산은 임의로 만들어내지 말 것.

## 산출물
- 6개 화면 및 핵심 모달 상태가 탐색 가능한 클릭형 프로토타입.
- 데스크톱/모바일 반응형, 컴포넌트/디자인 토큰.
- 정형 데이터가 들어가는 카드/테이블/차트 슬롯을 구현 가능한 구조로 표시.
- 디자인 검토용이며 DB, 인증, 시세 수집, 뉴스 크롤링, LLM, Push 발송, 주문 기능 구현 금지.
